# Anomaly 4-Class Audio Dataset

This dataset is prepared for the acoustic-motion anomaly detection project.

## Classes

- footsteps
- knocking
- glass_break
- normal

## Target

Initial target:

100 audio clips per class

Total:

400 audio clips

## Audio Format

- WAV
- Mono
- 16 kHz
- Approximately 3 seconds per clip

## Dataset Usage

This dataset is kept separate from ESC-50 and the existing project_audio dataset.

It will be used for:

1. Feature extraction
2. Model training
3. Model evaluation
4. Edge inference testing
